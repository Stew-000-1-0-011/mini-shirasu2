デッドタイム補償はデューティ比の誤差なので、電圧制限を通した後、デューティに直してから足す。

電圧制限は`duty_max * vdc`。vdcは測定値なので上限も毎サイクル引き直す。固定値にすると、負荷で母線が下がったときにデューティが1を超えてPWM側で黙って切られ、制御器が飽和に気づけない。

### 速度制御器: 速度 -> トルク
Jdω/dt = T - T_L
Ω(s) = (1/Js)(T(s) - T_L(s))
P(s) = 1/Js, D(s) = -T_L(s)

例によってI制御は欲しい。しかし、今回はPIで極零相殺はできない。Ki = 0となってしまう。
```
C(s) = (Kp*s + Ki)/s
P(s)C(s) = 1/Js * (Kp*s + Ki)/s
Y(s)/R(s) = PC / (1 + PC) = (Kp*s + Ki) / (Js^2 + Kp*s + Ki)
Y(s)/D(s) = P / (1 + PC) = s / (Js^2 + Kp*s + Ki)
```
オーバーシュートするし、その激しさと外乱の定常偏差の減り具合はトレードオフになる(らしい、追ってない)。

そこで、**2自由度PID**というのを使う。目標値をr, 出力をyとして
`PID-2(r, y) = Kp(br - y) + Ki(r - y) + Kd(cr - y)`
パラメータはKp, Ki, Kdに加えb, cだ。
積分項だけ新たなパラメータがないのは、入れてしまうと定常偏差が出てしまうからだ。

これを使うと、
```
Y/R = (bKp*s + Ki) / (Js^2 + Kp*s + Ki)
Y/D = s / (Js^2 + Kp*s + Ki)
```
となる。
Y/Dを決めた後、Y/Rを調節することができるわけだ。
これにより、外乱応答を調節した後、目標値応答の零点をいじれる(目標値応答の極は通常と変わらない)。
これにより目標値のオーバーシュートや立ち上がりの調節を、外乱と別に行えるわけだ。

実装はD項なしの`Kp(bu - ω) + Ki∫(u - ω)`。目標速度uは`±wmax`に制限し、制限後の値を積分にも使う。

### 制御理論赤点勢のためのTips
- モデル化は現実とのズレがつきものだよ！
- 極は、多項式/多項式型の伝達関数の分母 = 0の解。極を用いると伝達関数はΣ定数/(s - 極_i)^nの形で書ける。
- とりわけ多い外乱として定数的なものがある(トルク制御における重力等)。定数的な外乱をFFで消そうとしたとき、打ち消しきれないFFとの差も定数になる。また入力がステップ的であることも多い。
  ステップ入力やステップ外乱を入れるとすると、最終値の定理からCPが原点で極を持たないとき定常誤差が残る。これへの対処としてI制御を使う
- 逆に偏心やコギング等、周期的な誤差が支配的になることもある。この場合はFFで極力落としたり、「繰り返し制御」なるものを使うらしい。I制御で却って定常誤差がひどくなったりすることもあるよ！
- FFは極を変えないし、現実と少しのズレでもあればそのまま定常誤差になるが、オーバーシュート低減等に役立つ
- 極零相殺を不安定な極に対し試みないこと！ちょっとのズレがあるので結局発散するし、ぴったりだとしても理論的に不安定になるって言えるらしい。知らんけど。
- PIDの微分項など、`a[t] - a[t-1]`をやるものはローパスを入れるのが鉄則らしい。だからPIDの伝達関数のD項には普通ローパスぶんの一次遅れが入るらしい。ローパス付きの微分を近似微分とかいうらしい
